# Fake News Detection System

This project is an AI-based web application that detects whether a news article is real or fake using Machine Learning and NLP.

## Features
- Real-time news prediction
- Confidence score display
- Explanation of results
- Flask-based web interface

## Tech Stack
- Python
- Scikit-learn
- Flask
- HTML/CSS

##  Run Project
```bash
pip install pandas numpy scikit-learn flask
python app.py
